## HLS experiments

- **[hls.js server component](/hls/experiment?tech=hls.js) with next.js `<Script>`**

  A test to see if hls.js could be loaded via CDN from a `<script>` tag and attached to a
  static `<video>` element rendered by a server component.

  It kind of works, but client-side navigation (via `<Link>` component) breaks it because
  the `<video>` element is destroyed and replaced, but the `<script>` (or   `<Script>`)
  that initializes hls.js is not re-run. In the end, it's a silly   experiment, but it
  gives me a better feel for what happens to code in the   Willy Wonka factory that is
  a bundler.
